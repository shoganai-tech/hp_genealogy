# Источник положения родов

Откуда у рода деньги и вес. Основа: к = канон, н = решение автора, 0 = в каноне данных нет. Оценки предварительные, кроме отмеченных «согласовано».

- [[Люпины]] — бедность · к · оценка: бедные
- [[Принцы]] — без средств · к · оценка: данных нет
- [[Гонты]] — без средств; реликвии · к · оценка: заявленная древность без положения
- [[Нотты]] — влияние через список «28»; семья в тревоге за положение · н · оценка: тревожная старая семья (гипотеза) (гипотеза)
- [[Монтегю]] — возможно Визенгамот; связи с гоблинами, возможно долги · н · оценка: знать, возможно должники (гипотеза) (гипотеза)
- [[Розье]] — данных нет · 0 · оценка: данных нет
- [[Крэббы]] — данных нет · 0 · оценка: данных нет
- [[Гойлы]] — данных нет · 0 · оценка: данных нет
- [[Шафики]] — данных нет · 0 · оценка: данных нет
- [[Прюэтты]] — данных нет · 0 · оценка: данных нет
- [[Реддлы]] — земля (маггловские помещики) · к · оценка: джентри (маггловское)
- [[Булстроуды]] — земля и животноводство · н · оценка: аристократия земельная (животноводческая) (согласовано)
- [[Гринграссы]] — земля и, возможно, ювелирное дело / бижутерия · н · оценка: земля плюс ювелирная торговля (гипотеза) (гипотеза)
- [[Малфои]] — земля, деньги, влияние на Министерство · к · оценка: древняя земельная знать по канону; нынешний вес — деньги и политика
- [[Лавгуды]] — издательство · к · оценка: небогатые чудаки
- [[Уайлдсмиты]] — изобретение · к · оценка: ремесленно-изобретательские
- [[Поттеры]] — изобретение и торговля · к · оценка: новые деньги (по Флимонту), с оговоркой: линия Певереллов в цикле даёт «древность»
- [[Эвансы]] — маггловские · к · оценка: простой
- [[Блэки]] — наследство, родовой дом, золото · к · оценка: древняя знать (по канону, через имя, дом и браки)
- [[Лестрейнджи]] — наследство, сейф в Гринготтсе · к · оценка: богатая старая знать (источник денег неизвестен)
- [[Сэлвины]] — наше · н · оценка: решает автор
- [[Финчи]] — наше · н · оценка: решает автор
- [[Паркинсоны]] — не определено; «тёмная лошадка» · н · оценка: тёмная лошадка (специализация не выбрана) (гипотеза)
- [[Слагхорны]] — преподавание и связи · к · оценка: связи вместо денег
- [[Дамблдоры]] — преподавание, трактир · к · оценка: небогатая служилая
- [[Снейпы]] — рабочий слой (маггловский) · к · оценка: простой
- [[Тонксы]] — служба (авроры) · к · оценка: небогатая служилая
- [[Лонгботтомы]] — служба (авроры), старый дом · к · оценка: старая кровь, средний достаток (данных мало)
- [[Яксли]] — служба в Министерстве · к · оценка: чиновничье джентри
- [[Амбриджи]] — служба в Министерстве · к · оценка: выскочки (карьера через Министерство, статус заявлен)
- [[Диггори]] — служба в Министерстве · к · оценка: старая кровь, служилая
- [[Уизли]] — служба в Министерстве, бедность · к · оценка: старая кровь без денег и положения
- [[Филчи]] — служба при школе · к · оценка: простой
- [[Флинты]] — торговля рыбой (маггловские потоки между Британией и континентом) · н · оценка: торговый род (рыба) (согласовано)

# Министерство — фамилии сотрудников

> [!info] Что это
> Все фамилии со стороны **Министерства магии**, собранные для холста [[Министерство — отделы (канон).canvas|канонный холст]] и [[Министерство — отделы (авторский).canvas|авторский холст]]. Источники: Лексикон (список «Ministry of Magic Employees», 102 записи), Compendium, Pottermore (35 министров, «Ministers for Magic»), книги. «По версии автора» — решения Шоганай из vault.
> Колонка «Дети в Хогвартсе» — **предложения, не решения**: учебные годы 1991–1998 (рождения ~1974–1987); возраст сотрудников в каноне почти нигде не указан, оценка по годам их работы. Ничего из колонки «можно придумать» в vault не записано.

## Только по возрасту
Историческая даль, детей в школе 1991–98 быть не может, но фамилии удобны для линий: Пилливикл (ок. 1950), Макфарлан (глава игр 1957–68), Огден Боб (1920-е), Уркхарт (1950-е), Гамбойл.

## Министры магии (Pottermore) и фамилии
Историческая связь с родами vault: **Роули** (Дамокл, 1718–26), **Паркинсон** (Персей, 1726–33), **Диггори** (Элдрич, 1733–47), **Бут** (Альберт, 1747–52), **Лестрейндж** (Родольфус, 1835–41), **Флинт** (Жозефина, 1819–27), **Фоули** (Гектор, 1925–39), **Тафт** (Вильгельмина 1948–59; Игнатиус 1959–62), **Бэгнолд** (Милисент, 1980–90). Остальные фамилии в vault не используются: Гамп, Флэк, Гор, Кроуди, Наtchбулл, Осберт, Луфкин, Стамп, Гэмбол, Миллифатт, Орпингтон, Дюпон, Макфейл, Спавин, Крикерли, Эвермонд, Маклэрд, Спенсер-Мун, Лич, Дженкинс, Минчем.
Для сюжета: Паркинсон, Диггори, Фоули, Флинт, Роули и Лестрейндж — роды с министром в истории; это работает как «семейная гордость» или «былая слава».

## Невыразимцы (вики-навбокс, первоисточник не проверен)
Элтон Элдерберри, Грим Фоули, Дина Хекат, Оливия Грин, Гарет Гринграсс, Элоиза Минтамбл, Левина Монкстэнли, Регина Роули, Альберт Саллоу. Фамилии пересекаются с Фоули, Гринграссами, Роули. Для карточек нужно проверить первоисточник, прежде чем делать их частью рода.

## Что можно придумать (если захочется)
- Дети **Доулиша, Проудфута, Саваджа, Робардса, Уильямсона** (авроры): для ровесников Гарри разумно давать детей, которые из семей авроров; для Гриффиндора/Хаффлпаффа подходят «суровые» дети, а для Слизерина дети чиновников.
- Дети **Мокриджа, Кроукера, Туайкросса, Перкинса, Басила**: «второй ряд» Министерства; хорошо дают массовку курса.
- **Стеббинс-старший** (аврор): превращает студента Стеббинса в сына аврора.

## Заметки по источникам
- Должность «глава правопорядка при Пожирателях» у Яксли подтверждается Compendium; до него Тикнесс (по Лексикону до августа 1997).
- Список невыразимцев (9 имён) — из навбокса вики, первоисточник не найден.
- Боб Огден — глава Отряда магического правопорядка (1920-е); Тиберий Огден — член Визенгамота (ОФ), не обязательно родственник.

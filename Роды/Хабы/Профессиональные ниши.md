# Профессиональные ниши

Какие занятия уже «закреплены» за родами в нашей базе, а какие свободны. Основа: канон и решения автора, см. [[Источник положения]]. Таблица оценивает только базу, а не весь мир.

## Занято

| Ниша | Роды и основание |
|---|---|
| Земля и сельское хозяйство | Булстроуды (животноводство, решение автора), Малфои (Уилтшир, канон), Реддлы (маггловские помещики, канон), Гринграссы (земля, гипотеза) |
| Торговля (рыба, маггловские поставки) | Флинты (решение автора) |
| Ювелирное дело, бижутерия | Гринграссы (гипотеза автора) |
| Визенгамот | Монтегю (гипотеза автора), связи с гоблинами |
| Изобретение и торговля | Поттеры (зелье для волос, Флимонт), Уайлдсмиты (летучий порох), Дамблдоры (трактир «Кабанья голова», Аберфорт) |
| Издательство | Лавгуды («Придира») |
| Министерство: аврорат и правопорядок | Тонксы, Лонгботтомы (авроры), Яксли (правопорядок) |
| Министерство: чиновники | Амбриджи (Орфорд, Долорес), Уизли (Артур), Диггори (Амос, магические существа), Шафики (межд. сотрудничество, роль в цикле) |
| Хогвартс: преподавание и штат | Слагхорны, Дамблдоры, Снейпы (Северус), Люпины (Римус), Филчи (завхоз) |
| Политическое влияние и деньги за кулисами | Малфои (финансирование кампаний, совет попечителей), Нотты (список «28») |
| Наследство и золото в банке | Блэки, Лестрейнджи, Поттеры (сейф родителей Гарри) |

## Свободно в нашей базе (кандидаты на роли для родов без занятия)

| Ниша | Роды и основание |
|---|---|
| Больница Св. Мунго, целительство | в базе никого; в каноне есть, но чьи это семьи — нужно решать автору |
| Суд (судьи, судебная практика) | в базе нет; Визенгамот — место в «палате лордов», а не специализация |
| Отдел тайн | в базе пусто; для Ноттов или Яксли возможна роль |
| СМИ («Ежедневный пророк») | в базе пусто |
| Гринготтс, финансы | в базе пусто (в каноне Гринготтс управляют гоблины, люди-банкиры не показаны) |
| Торговля артефактами и редкостями | в базе пусто; в каноне это Бёрки («Горбин и Бёрк») и Олливандеры, они в базе отсутствуют |
| Профессиональный квиддич | в базе пусто |
| Дипломатия, международные связи | в базе почти пусто (Шафики, роль в цикле) |
| Роды без назначенного занятия | Паркинсоны («тёмные лошадки»), Розье, Крэббы, Гойлы, Принцы, Прюэтты: в каноне данных нет |

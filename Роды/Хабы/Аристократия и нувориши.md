# Аристократия и нувориши (по фамилиям)

Оценка слоя по этимологии и реальным носителям. Это гипотезы, не вердикты. Не сверено = по памяти.

## аристократическая (старая знать)
- [[Лестрейнджи]] (Lestrange): Высокая.
- [[Малфои]] (Malfoy): По канону — высокая; по реальной этимологии оценить нельзя.
- [[Монтегю]] (Montague): Высокая.

## знать средней руки (джентри)
- [[Яксли]] (Yaxley): Средняя.
- [[Булстроуды]] (Bulstrode): Высокая.
- [[Реддлы]] (Riddle / Riddell): Средняя.
- [[Сэлвины]] (Selwyn): Средняя-высокая.
